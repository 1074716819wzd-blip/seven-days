# 七日 · 任务与日常

一个手机优先、只在本机保存数据的任务小应用，提供月历总览和 7 天执行视图。没有账号、后台、云数据库、AI API 或预设任务。

项目位置：`D:\小应用\seven-days`

## 启动与电脑测试

需要 Node.js 22.18+（本机使用 Node.js 24）。依赖已经安装。

在 PowerShell 中运行：

```powershell
cd D:\小应用\seven-days
npm.cmd run dev
```

打开终端显示的 Local 地址，默认是 http://localhost:5173/seven-days/ 。`npm.cmd` 避开本机 PowerShell 对 npm.ps1 的执行策略限制，不需要修改系统执行策略。

测试正式构建与离线功能：

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4173 --strictPort
```

电脑打开 http://localhost:4173/seven-days/ 。首次联网打开，等待“数据与安装”中显示“离线资源已就绪”；随后可以在开发者工具 Network 中启用 Offline，再刷新和编辑记录。开发模式不启用离线缓存。

浏览器开发者工具的设备模式可以检查 320px、375px、390px 等手机宽度。

## 手机访问与安装

### 同一 Wi-Fi 预览

1. 在电脑运行上面的 preview 命令，并保持终端开启。
2. 电脑与手机连接同一 Wi-Fi。
3. 手机打开终端显示的 Network 地址并使用 `/seven-days/` 路径；局域网 IP 会变化，以终端输出为准。
4. 如果无法访问，检查网络是否隔离设备，以及 Windows 防火墙是否允许 Node.js 通过专用网络。

局域网 HTTP 地址可以测试任务、消费和本地备份。**手机上的正式 PWA 安装和离线缓存需要 HTTPS**；普通局域网 HTTP 不满足条件。电脑 localhost 是浏览器允许的开发例外。

### 长期使用

将 `dist` 文件夹放到有 HTTPS 的静态网站托管上即可，不需要后端或数据库。发布的是应用文件，个人任务仍只留在浏览器 IndexedDB。已准备 GitHub Pages 工作流，推送到 main 后自动构建部署；仓库授权和 Pages 设置见 [DEPLOYMENT.md](DEPLOYMENT.md)。当前尚未上线。

- iPhone：使用 Safari 打开 HTTPS 地址 → 分享 → 添加到主屏幕。
- Android：使用支持 PWA 的浏览器打开 HTTPS 地址 → 浏览器菜单 → 安装应用／添加到主屏幕；支持时应用“数据与安装”中也会出现安装按钮。
- 首次联网打开并缓存完成后，再从主屏幕启动即可离线使用。

浏览器要求参考：[MDN：让 PWA 可安装](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

## 使用规则与已实现功能

- 首次选择周期起始日期、名称和颜色；以后自动按连续 7 天衔接，跨月跨年正常。
- 首页默认打开当前月份，顶部“月历｜7天”切换视图。“7天”保留原来的周期页面，左右切换周期，“回到本期”返回今天所在周期，“选日期”直接打开任意日期。
- 每个阶段可以随时改名、改颜色。未编辑的阶段名称与颜色按周期位置确定，不评价表现。
- 首页 7 张日期卡片展示日期、已完成／总任务数、四舍五入后的百分比、进度条和消费。
- 任务可以新增、点击文字修改、删除、完成／未完成切换；任务数量变化后实时计算进度。
- 0 条任务显示 0%；全部完成显示 ✓ 100%。过去、今天、未来均可编辑。
- 消费输入当天总金额，点击“保存金额”。金额以整数分存储；日均消费始终为本周期总金额除以 7，不是除以已记录天数。
- “应用到其他日期”支持当前日期之后 N 天或任意起止日期范围，包含范围首尾，支持跨周期。
- 复制只复制任务文字，新任务均为未完成；追加保留原任务和状态，覆盖替换原任务和状态；两种方式都保留目标日期消费。
- “粘贴任务”每个非空行解析为一条任务，会移除常见列表序号／项目符号；预览后选择当前日、今天、未来 N 天或指定范围及追加／覆盖方式。
- 所有批量操作先展示条数、天数、日期范围、模式和影响，再确认执行。关闭确认页不会修改记录。
- IndexedDB 自动保存；同源多标签页通过事务和 BroadcastChannel 避免旧快照覆盖、同步显示。
- JSON 备份导出、格式校验、恢复前确认；恢复替换全部数据，错误备份不会改动原数据。
- PWA 清单、192／512 图标、Apple 图标、离线缓存和安装说明。
- 手机单列卡片布局、大按钮，无复杂导航、图表或模板。

## 月历总览

- 月历按周日到周六排列，支持上／下月、跨年和闰年；“今天”返回当前月份。
- 日期格显示任务完成率、消费和阶段底部色条。无任务显示“暂无任务”，不会算作 100%；全部完成显示“✓ 100%”；今天有轻边框和日期强调。
- 同阶段日期使用现有阶段颜色。修改 7 天视图的阶段颜色后，月历同步更新。
- 点击日期进入同一个每日详情，历史、当前、未来日期均可编辑。“返回月历”保留原先月份；详情刷新后也能返回该月份。
- 本月平均完成率：只统计有任务的日期，取各日“完成数／任务数”的算术平均，最后四舍五入为整数百分比。有任务但尚未完成的日期计为 0%，无任务日期不参与；一个都没有时显示“—”。
- 本月累计消费：求和该月已有每日记录的金额，包含只有消费、没有任务的日期。不计其他月份。
- 日期格中的金额超过千元时用千／万／亿简写，完整精确金额可在每日详情查看；月度累计仍显示完整金额。
- 月历直接读取现有 `days` 和 `periods`，没有第二套任务／消费数据，也不改变 IndexedDB 或 JSON 备份结构。
- 在 320–430px 宽度保持一行七列，金额很长时月汇总自动改为纵排。

已有安装版如果仍显示旧页面：联网打开应用，在“数据与安装”中点击“更新应用（记录会保留）”。不要清除网站数据。

## 本地数据与备份

数据存在**当前设备、当前浏览器、当前网站地址**的 IndexedDB：

- 数据库：`seven-days`
- 对象存储：`app`
- 键：`data`

不在项目源代码或 dist 目录中。不同端口、HTTP／HTTPS、不同域名、浏览器和设备拥有不同的数据空间。

**备份**：右上角“数据与安装” → “导出备份”，保存下载的 `七日备份-日期.json`。包含版本、周期起点、已记录阶段及名称／颜色、每日日期、任务文字、任务完成状态和消费金额。未编辑阶段由周期起点与规则计算，不需要逐一保存。

**恢复**：在目标设备打开应用，若为首次使用先创建初始周期，再进入“数据与安装” → “导入备份” → 选择 JSON → 核对记录数量 → “确认替换并恢复”。恢复前可在确认页导出当前数据。

更换手机、换网址、清除网站数据或卸载前先导出备份。请使用普通浏览模式；浏览器可能清理网站存储，离线缓存不等于数据备份。

## 技术与代码

React 19 + TypeScript + Vite + 原生 IndexedDB；`vite-plugin-pwa` / Workbox 生成离线资源；无需状态管理库、UI 库和业务服务器。

| 文件 | 职责 |
| --- | --- |
| `src/App.tsx` | 首页、日期详情及编辑／批量／备份交互 |
| `src/CalendarView.tsx` | 月历格子、月份切换、月度汇总 |
| `src/calendar.ts` | 月份运算、日期网格、汇总口径、格子金额格式 |
| `src/data.ts` | 日期、周期、金额、进度、批量任务和备份校验 |
| `src/storage.ts` | IndexedDB 读写；未来换存储可从此处接入 |
| `src/style.css` | 手机优先布局 |
| `vite.config.ts` | 构建与 PWA 配置 |
| `tests/data.test.ts` | 核心逻辑和存储测试 |
| `tests/calendar.test.ts` | 月份、闰年、星期位置、月度统计与金额格式测试 |
| `e2e/app.spec.ts` | 浏览器真实交互与离线测试 |
| `e2e/calendar.spec.ts` | 月历交互、两种视图同步、窄屏和离线测试 |

## 自动测试

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
```

核心测试使用 Node.js 内置测试工具和 fake-indexeddb。浏览器测试使用 Playwright 与本机 Microsoft Edge，自动开启生产预览，采用手机尺寸和上海时区。测试数据位于独立临时浏览器环境，不会写入你日常使用的浏览器。

测试覆盖详见 `TEST-REPORT.md`。
